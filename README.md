# Website Redesign: SEO Safety Checklist

Before a redesign goes live:
1. List every URL that has clicks or impressions in Search Console. These URLs must keep working, or 301 to the exact closest page.
2. Count the sitemap URLs before and after the deploy.
3. Open the 3 top pages and check they return 200, are indexable, self-canonical and show full content.
4. Check internal links resolve and no page is empty.
